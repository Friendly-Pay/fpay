## О проекте

FPay (Friendly Pay) — платёжный онлайн-эквайринг, по сути онлайн-касса. Клиент
открывает страницу оплаты, видит сумму, жмёт «Оплатить» и платит. Плюс есть
страница создания платежа, для клиентов без личного сайта.

## Стек

React 18 + TypeScript + Vite + Zustand + axios. Пакетный менеджер PNPM.

## Код

### Компоненты

**Структура файлов**

- Именование файлов и экспортов — `PascalCase`.
- Один компонент = папка `ComponentName/` с `ComponentName.tsx` + `ComponentName.module.scss` (co-location, одинаковые имена).
- Группировка по домену: `ui/` (переиспользуемые), `payment/` (доменные), `layout/`.
- `index.tsx` — только для namespace-объекта: `export const PaymentDetails = { Table, Row }`. Не для реэкспорта одного компонента.

**Экспорт и объявление**

- Именованный экспорт: `export const Name` (не `export default`). Исключение — legacy типа `Qr`.
- Основной паттерн: `export const Name: React.FC<Props> = ({ ... }) => { ... }`.
- Children — оборачивай пропсы в `PropsWithChildren<Props>`, не добавляй `children` вручную.
- Ref — `React.forwardRef<HTMLEl, Props>((props, ref) => ...)`.
- `Name.displayName = 'Name'` ставим обязательно и для `forwardRef`, и для `memo`.

**Пропсы**

- `interface NameProps` по умолчанию; `type` — когда много опциональных полей/юнионов.
- JSDoc `/** ... */` на русском — только для неочевидных пропсов. Очевидное (`className`, `loading`, `disabled` и т.п.) не комментируем.
- Варианты — строковые юнионы.
- Нативные атрибуты — через `extends ...HTMLAttributes<...>` + `...restProps`, дефолты в деструктуризации.

**Стили**

- Только CSS Modules: `import styles from './Name.module.scss'`.
- Склейка через `classnames` как `cn`: `className={cn(styles.root, className)}`. Внешний `className` — последним аргументом.
- Корневой класс — `styles.root` или семантика (`styles.card`).
- Значения из CSS-переменных (`var(--radius)`); динамика — через `style={{ ... }}`.

**Локализация и мелочи**

- Текст только через `t('...')`; HTML в тексте (`<br/>`) — `dangerouslySetInnerHTML={{ __html: t('...') }}`. Переводы — в `src/localization/translates/` (`ru.ts`, `th.ts`).
- `img`: всегда `loading="lazy"` + `alt`.

**Порядок импортов (сверху вниз)**

1. Компоненты
2. `classnames` as `cn`
3. `styles` — всегда последним

### Контроллеры

**Контроллер** — headless-компонент (рендерит `null`), в который выносится вся фоновая side-effect-логика жизненного цикла (поллинг, таймеры, обратный отсчёт, смена статусов). Задача — отделить «мозги» от «внешности»: UI остаётся чисто презентационным и только читает готовое состояние из стора, а вся императивная работа с эффектами и синхронизацией живёт в одном месте, а не размазана по вью.

Пишется как `React.FC` без пропсов, который ничего не рендерит (`return null`) — вся логика в `useEffect` с обязательной очисткой ресурсов в return. Состояние читает из стора селекторами и пишет обратно через его actions; наружу общается только через стор, не через пропсы.

Можно оставлять коментарии на руском, под ветвление логики.
